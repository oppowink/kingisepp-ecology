# ЭкоБиоМониторинг

Открытая система экологического скрининга: статический фронтенд, восемь Vercel Functions и Supabase.

## Подготовка Supabase

Добавьте в Vercel переменные из `.env.example`, затем выполните миграции по порядку:

1. `supabase/001_profiles.sql`
2. `supabase/002_learning_and_certificates.sql`
3. `supabase/003_monitoring_requests.sql`
4. `supabase/004_feedback_messages.sql`
5. `supabase/005_organizations_curators_and_passports.sql`
6. `supabase/006_training_landmarks_and_integrity.sql`
7. `supabase/007_multitree_requests.sql`

Шестая миграция добавляет ролевое обучение, контрольные точки листьев, отпечатки файлов, флаги целостности и журнал модерации. Седьмая сохраняет состав заявки из двух–четырёх деревьев; обе обязательны для новой версии. Секретный ключ Supabase разрешено хранить только в Vercel Functions.

## Рабочий сценарий

1. Участник проходит обязательный курс и тест.
2. Куратор создаёт организацию, проект и территорию, выдаёт код подключения и при необходимости назначает участника.
3. Участник заполняет паспорт территории и 2–4 деревьев, загружает обзорное фото и 10–30 фотографий листьев для каждого дерева.
4. Браузер предварительно проверяет разрешение и светлый фон, считает SHA-256 и предлагает поставить 12 точек на каждом листе. Вид растения проверяет модератор.
5. Модератор проверяет фотографии, паспорт и точки. Небольшие ошибки можно исправить в редакторе.
6. После одобрения сервер рассчитывает ФА по проверенным точкам. Среднее значение точки вычисляется из средних значений деревьев.
7. Модератор проверяет результат и публикует точку. Только опубликованные заявки видны на карте.

## Что именно автоматизировано

В репозитории есть воспроизводимый расчёт ФА `landmark-fa-v1`. Он получает проверенные координаты точек, вычисляет три относительных различия и усредняет их. Это автоматический расчёт, а не нейросетевая постановка точек.

Файл обученной модели ключевых точек в исходный репозиторий не передан. Поэтому сайт не выдаёт эвристику за нейросеть. Для полной автоматизации модель нужно подключить перед ручным редактором, а модератору оставить возможность исправления предсказанных точек.

Проверка вида на клиенте сейчас является предварительной проверкой качества фотографии. Окончательное решение о виде и пригодности листа принимает модератор.

## Защита от повторного использования фотографий

- уникальный SHA-256 каждого файла;
- запрет повторного использования уже загруженного файла;
- случайный шестизначный код полевого набора;
- время формирования заявки;
- координаты устройства и точность геолокации, если участник разрешил доступ;
- проверка попадания в радиус территории куратора;
- журнал действий модератора.

Эти меры снижают риск подмены, но не являются абсолютным доказательством места сбора. Спорные случаи проверяет человек.

## Роли и обучение

Курсы участника, куратора и модератора обязательны. В тестах показывается по одному вопросу. Результат хранится в Supabase. Сертификат открывается после прохождения курса, но скачивание намеренно отключено до добавления утверждённых макетов.

## Состав полного комплекта

- `img/games/` — исходные фото, две очищенные игровые версии фотографий берёз и отдельные вырезки листьев с прозрачным фоном. Игры используют общую шапку, подвал, тему и сетку сайта.
- `img/author-polina.png` — портрет автора без фона из первого присланного снимка; исходники обоих портретов и все остальные исходные фотографии лежат в `assets/original-photos/`.
- `img/home/aktualnost/avtomobil-hd.png` — версия иллюстрации автомобиля с увеличенным разрешением.
- `docs/` — обновлённые методические пособия участника, модератора и куратора в PDF и DOCX. Все три описывают одну заявку как 2–4 дерева с 10–30 отдельными фотографиями листьев на каждое дерево. Модель автоматической постановки точек пока не подключена.

Секреты и содержимое базы данных в архив не включены. После загрузки сайта на хостинг нужно проверить реальный вход, хранение фотографий и публикацию заявок в своей конфигурации Supabase.

Обработанные игровые фотографии предназначены только для учебного интерфейса. Исходные файлы автора сохранены без изменений в `assets/original-photos/`; обработанные вырезки и версии с очищенным фоном не используют для измерения ФА или проверки подлинности наблюдения.
