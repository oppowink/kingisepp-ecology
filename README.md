## Обновление существующего сайта

1. Замените файлы проекта содержимым этого архива. Важно загрузить не только index.html, но и css, js, data, api, server.
2. Если база уже создана, выполните supabase/008_status_constraints_repair.sql в SQL Editor Supabase. Для новой базы: 001_profiles.sql, затем 002–008. 001_users.sql — историческая альтернативная схема, вместе с 001_profiles.sql не требуется.
3. Обновите развёртывание Vercel, чтобы появились /api/assistant и /api/feedback. Обновление только GitHub Pages не устанавливает серверные функции.
4. В окружении Vercel поставьте ASSISTANT_ENABLED=true и ASSISTANT_PROVIDER=legacy. ASSISTANT_CHAT_URL по умолчанию равен адресу прошлогоднего адаптера. ASSISTANT_MODEL по умолчанию gpt-4o-mini. Если адаптер требует отдельный ключ, укажите ASSISTANT_API_KEY только в окружении сервера.
5. Если в окружении осталось ASSISTANT_ENABLED=false, измените его: иначе будет только справка. После изменения переменных нужен redeploy.
6. На GitHub Pages помощник и обратная связь обращаются к https://kingisepp-ecology.vercel.app. Если домен сервера изменится, обновите адрес в js/assistant.js и js/feedback.js. Личные кабинеты лучше открывать на Vercel: там сервер работает на том же домене.

Для прямого подключения Yandex AI Studio: ASSISTANT_PROVIDER=yandex, YANDEX_API_KEY, YANDEX_FOLDER_ID, YANDEX_TEXT_MODEL. Приватные ключи не добавлять в HTML/JS и GitHub. Адрес старого адаптера использует GPT-совместимый протокол; название gpt-4o-mini само по себе не подтверждает, какая модель работает внутри адаптера.

## Классификатор и Colab

На странице classifier.html подключён актуальный экспорт ecobio_leaf_classifier.tflite из ecobio_classifier_results.zip. Три класса в порядке model_info.json, вход float32 [1,192,192,3]. Изображение приводится к 192×192 с сохранением пропорций и нулевыми полями (resize_with_pad); нормализация встроена в экспорт, повторно не применяется. TensorFlow.js и TFLite WASM загружаются с CDN, фотографии не отправляются на сервер. Это предварительная отдельная проверка; результат не записывается в заявки и не заменяет модерацию. Supabase-миграция для этой страницы не требуется.

Порог уверенности не задан: model_info.json содержит null; выбирать его по тестовой таблице как доказанную гарантию качества нельзя. Страница показывает все три оценки без автоматического допуска.

По test_predictions.csv верны 191/194 (98,45%). Macro F1 0,966543; weighted F1 0,984851. Реальный split: 895/191/194 = 1280 файлов, классы 1079/101/100. metrics.json содержит противоречащие этим таблицам 2160 и 1080/540/540: исходные метаданные сохранены без подмены, в интерфейсе приведены проверенные таблицы. 411 записей аудита — нечитаемые служебные ._ файлы. Совпадений SHA256 между split не найдено; независимость листьев одного скана/дерева этим не доказана.

Проверены структура TFLite, порядок классов, таблицы результатов и подготовка размеров. Запуск самого WASM-классификатора на реальных фотографиях в браузере в этой среде НЕ проверен: перед защитой проверьте страницу на Vercel и несколько известных фотографий. Старый семикатегорийный Teachable Machine не используется.

В приложенном отдельно исправленном Colab используется пять признаков и |L-R|/(L+R), как в браузере и сервере. Исходный блокнот использовал три признака и полусумму в знаменателе. Ранее полученные в нём CSV нужно пересчитать по исходной разметке; опубликованные исследовательские значения в этой сборке не изменены.
