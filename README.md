# ЭкоБиоМониторинг

Статический фронтенд и Vercel Functions для Supabase.

## Регистрация без почтового кода

Регистрация выполняется по e-mail и паролю. Серверная функция создаёт подтверждённого пользователя через Supabase Admin API, поэтому SMTP для первого входа не требуется. Секретный ключ используется только внутри Vercel Functions.

Пароль при регистрации должен содержать минимум 8 символов, заглавную и строчную буквы, цифру и спецсимвол. Повтор пароля проверяется на фронтенде и на сервере.

Перед деплоем добавьте в Vercel переменные из `.env.example`:

- `SUPABASE_URL`;
- `SUPABASE_PUBLISHABLE_KEY` или `SUPABASE_ANON_KEY`;
- `SUPABASE_SECRET_KEY` или `SUPABASE_SERVICE_ROLE_KEY`;
- `SESSION_SECRET`, случайная строка длиной не менее 32 символов;
- `APP_URL`, адрес опубликованного сайта.

В Supabase SQL Editor по порядку выполните:

1. `supabase/001_users.sql`
2. `supabase/002_learning_and_certificates.sql`

Вторая миграция добавляет прогресс обучения, сертификаты и поля статуса обучения в профиль.

Серверный secret/service-role ключ нельзя добавлять в HTML, клиентский JavaScript или переменные с префиксом `PUBLIC`.

## Что уже подключено

- обучение волонтёра из 6 шагов и теста на 7 вопросов;
- сохранение статуса обучения локально и через `/api/education/complete`, если доступен Vercel API;
- блокировка добавления точки до прохождения обучения;
- сертификат волонтёра-исследователя через печатную страницу браузера;
- админский блок в `moderator.html`: тестовый сертификат волонтёра, статистика заявок, назначение роли модератора;
- модераторское обучение и сертификат модератора пока отключены.
